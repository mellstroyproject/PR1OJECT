# NextProject

Сайт для CS2-сервера NextProject: баны, админки, магазин, лидеры, правила, Telegram-бот и чат в стиле мессенджера с голосовыми звонками.

## Что есть на сайте

**Сервер CS2**
- Баны и муты, выдача и продление админок, покупка админки с автовыдачей на сервер.
- Магазин, промокоды, лидеры, правила.
- Вход через Steam. Без входа чат и звонки недоступны.

**Чат и голос (раздел «Чат»)**
- Каналы по категориям, как в мессенджерах: «Важное», «Общение», «Тикеты», «Администрация», «Проверка».
- Текстовые каналы: ответы, реакции, редактирование и удаление своих сообщений, упоминания @ник.
- Групповые упоминания: `@админы` (только уведомляет администрацию, раз в минуту для игроков) и `@все` (только для администрации).
- Личные сообщения с профилем собеседника и кнопкой звонка. Раздел «Люди» показывает всех игроков с вкладками «В сети» и «Все».
- Голосовые каналы и звонки в личке на WebRTC: звук идёт напрямую между игроками, сервер передаёт только сигналы.
- Демонстрация экрана с компьютера и показ камеры с телефона.
- Совместный просмотр видео: YouTube с синхронизацией, VK видео, остальные ссылки открываются отдельно.
- Уведомления: плашки на сайте, push-уведомления (даже когда сайт закрыт), звук входящего звонка.

**Telegram-бот**
- Привязка аккаунта через «Войти через сайт».
- Команда `/call ник` создаёт звонок игроку на сайте и присылает ссылку.
- Если игрок на сайте не в сети, бот сообщает о звонке с кнопкой.
- Промокоды, пополнение монет, баны из Telegram для администраторов.

**Установка на телефон**
- Сайт ставится на домашний экран через «Поделиться» → «На экран «Домой»» в Safari и Chrome.
- Работает оболочка без интернета. API и вход через Steam всегда онлайн.

## Структура файлов

| Файл | Что делает |
|---|---|
| `server.js` | основной сервер: Steam, база данных, магазин, Telegram-бот, раздача файлов |
| `messenger.js` | API чата, голоса, уведомлений и звонков из Telegram |
| `messenger.html` | интерфейс чата и голосовых каналов (открывается в iframe) |
| `index.html` | главная страница сайта, плавающий чат, плашки уведомлений |
| `sw.js` | service worker: кэш оболочки и push-уведомления |
| `manifest.webmanifest` | описание приложения для установки на домашний экран |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | иконки приложения |
| `ring.mp3` | мелодия входящего звонка |
| `battleship.js` | мини-игра «Морской бой» |

Файлы `messenger.js`, `messenger.html`, `ring.mp3`, `sw.js`, иконки и манифест лежат рядом с `server.js`.

## Установка

1. Установить зависимости:
   ```bash
   npm install
   ```
   Среди них должен быть пакет `web-push` (для push-уведомлений) и `grammy` (для Telegram-бота).

2. Задать переменные окружения (на Render — в разделе Environment).

3. Запустить сервер:
   ```bash
   npm start
   ```

При первом запуске таблицы в базе данных создаются сами.

## Переменные окружения

**Telegram**
- `TG_BOT_TOKEN` — токен бота от @BotFather.
- `TG_ADMINS` — Telegram ID владельцев через запятую.
- `TG_CHANNEL` — канал, на который нужно подписаться (например, `@Next1Project`).
- `TG_WEBHOOK_SECRET` — секретная строка для webhook бота.
- `TG_BONUS_HOURS`, `TG_TZ_OFFSET` — необязательные настройки бонусов и часового пояса.

**Push-уведомления**
- `VAPID_PUBLIC` и `VAPID_PRIVATE` — ключи, которые создаются командой `npx web-push generate-vapid-keys`. Приватный ключ нигде не публикуй.
- `VAPID_SUBJECT` — контакт в формате `mailto:почта@example.com`.

**Звонки через сложные сети (необязательно)**
- `TURN_URL` — адрес TURN-сервера, можно несколько через запятую.
- `TURN_USER` и `TURN_PASS` — логин и пароль TURN-сервера.

Без TURN звонки работают, но у части игроков за NAT или мобильным интернетом звук может не пройти.

## Как устроены звонки

- Каждый участник соединяется напрямую с каждым (схема «mesh»). Это подходит для 5–8 человек в одном звонке.
- Сигналы WebRTC (предложения, ответы, ICE-кандидаты) сервер хранит в памяти и отдаёт клиентам при опросе раз в секунду.
- Если сервер перезапустится, все текущие звонки разорвутся, и участникам придётся зайти снова.

## Ограничения

- Голос не может работать в фоне на iPhone: iOS приостанавливает страницу, когда приложение свёрнуто.
- Показ экрана с iPhone не поддерживается браузерами. Вместо него на телефоне включается камера.
- Telegram-боты не умеют совершать настоящие голосовые звонки. Звонки из Telegram открываются как ссылка на сайт.
- Встраивать можно только видео с YouTube и VK. Остальные сайты открываются отдельно по ссылке.
- Синхронизация видео работает только для YouTube.

## Лицензия

Проект приватный. Использовать его для другого сервера или публиковать без разрешения владельца нельзя. Музыка и мелодии в `ring.mp3` защищены авторским правом их владельцев: используй только то, на что у тебя есть права.
